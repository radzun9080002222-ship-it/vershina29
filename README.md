# Вершина — Архангельск

Городской сайт для https://vershina29.ru/. Публикация планируется в Yandex Object Storage (основной домен и www с HTTPS-редиректом).

## Состояние 15.11.2026

Исходники локализованы, обычные утверждённые ставки и последние правки калькулятора сохранены. Герой — AI-иллюстрация с видом на Северную Двину и Гостиный двор; до/после — иллюстрации, не выполненные заказы. Контакты общие с шаблоном.

Сайт ещё не объявлен запущенным. Создан отдельный счётчик Метрики 114256874 под dima.radzun с Вебвизором, строгим доменом и поддоменами; его ID подключён к исходникам. Основной и www-бакеты созданы, хостинг и HTTPS-редирект настроены. Цели, Вебмастер, DNS-зона, SSL и отдельный deployer/Secrets требуют завершения. Чужая аналитика и проверка Вебмастера из шаблона удалены.

Cloud workflow пока запускается только вручную. После создания bucket-scoped deployer и сохранения новых ключей только в Actions Secrets включить push main и проверить deployment. Не переносить ключи в файлы, журнал или Git.

Проверки: pnpm install --frozen-lockfile; pnpm build.
