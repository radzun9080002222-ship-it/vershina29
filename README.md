# Вершина — Архангельск

Городской сайт для https://vershina29.ru/. Опубликован в Yandex Object Storage; www перенаправляется на основной адрес по HTTPS.

## Состояние 15.11.2026

Исходники локализованы, обычные утверждённые ставки и последние правки калькулятора сохранены. Герой — AI-иллюстрация с видом на Северную Двину и Гостиный двор; до/после — иллюстрации, не выполненные заказы. Контакты общие с шаблоном.

Отдельный счётчик Метрики 114256874 под dima.radzun: Вебвизор, строгий домен и поддомены, пять точных JS-целей click_phone/click_max/click_telegram/click_whatsapp/calc_interaction. Права Вебмастера подтверждены; собственный метатег опубликован. Основной и www-бакеты Standard1ГБ, публично только чтение объектов. DNS-зона настроена, SSL root/www выпущен и подключён. Полная готовность требует завершения распространения HTTPS и оставшихся настроек поиска: связи Метрики с Вебмастером, Sitemap и переобхода.

Cloud workflow запускается при push main и вручную. Отдельный deployer имеет storage.editor только в основном бакете. Новый S3-ключ сохранён только в GitHub Actions Secrets. Не переносить ключи в файлы, журнал или Git. Первичная публикация и release-check успешны.

Проверки: pnpm install --frozen-lockfile; pnpm build.
